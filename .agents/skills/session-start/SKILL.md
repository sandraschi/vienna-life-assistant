# Vienna Life Assistant — session start skill

Use when a session begins: recall the ViLife life-admin surface.

**Before starting work:**
1. Morning brief: `vienna_life(operation="life_brief")`
2. Active medications: `vienna_health(operation="meds")`

**At end of work, save insights:**
- Log doctor visits, trips, expenses, or contacts you captured via the
  `vienna_health` / `vienna_travel` / `vienna_life` / `vienna_contacts` tools.
